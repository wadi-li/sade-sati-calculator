# Калькулятор Саде Сати

Офлайн-калькулятор периодов **Саде Сати** и **Шани Дхайи** (ведическая астрология, сидерический зодиак). Один HTML-файл без зависимостей: работает в браузере без интернета.

> Саде Сати и Дхайя — понятия джйотиша без научного подтверждения. Программа считает положения Луны и Сатурна; толкования — астрологическая традиция, а не прогноз.

## Возможности

- Знак Луны, накшатра и пада на момент рождения.
- Все периоды Саде Сати в виде иерархии: вход, три фазы, ретро-откаты, временные выходы, окончательный выход.
- Шани Дхайя: Кантака (4-й знак от Луны) и Аштама (8-й), со справкой и всплывающими подсказками.
- Таблица ключевых событий жизни: для каждого события показано, на какой период Сатурна оно пришлось.
- Круговая диаграмма жизни (12 часов — рождение) с экспортом в SVG и PNG.
- Автоопределение смещения UTC на момент рождения по городу (база IANA tzdata браузера, летнее и декретное время, LMT).
- Режимы: «По дате рождения», «По знаку Луны», «Все знаки сейчас», «Справка».
- Айанамши: Лахири, Раман, KP, Фаган–Брэдли, своя, тропический зодиак.
- Светлая и тёмная темы, автосохранение в браузере, сохранение и загрузка JSON, экспорт CSV.
- Встроенная справка с поиском, печатью и словарём терминов.

## Запуск

Откройте `index.html` в любом современном браузере (Chrome, Edge, Firefox, Safari). Установка и интернет не нужны.

Онлайн-версия (после включения GitHub Pages): https://wadi-li.github.io/sade-sati-calculator/

## Модель и точность

| Параметр | Значение |
|---|---|
| Алгоритм | Орбитальные элементы P. Schlyter + основные возмущения (Луна — 12 членов, Сатурн — великое неравенство Юпитер–Сатурн) |
| Луна | ≈ 1–3′ (проверка по примеру Meeus 47.a) |
| Сатурн | ≈ 1–2′; даты смены знаков — обычно в пределах суток |
| Диапазон дат | 1900–2100 |
| Часовые пояса | IANA tzdata браузера; до 1970 г. история отдельных городов может быть упрощена |

Контрольные даты (Лахири): Сатурн входит в Козерог 24.01.2020, в Водолей 29.04.2022, в Рыбы 29.03.2025, в Овен 03.06.2027.
